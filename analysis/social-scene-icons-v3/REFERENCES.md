# Social Scene 아이콘 검토

사용자가 제공한 디자인 자료 중 아이콘 관련 출처를 검토했습니다. 아래 후보 SVG는 직접 작성한 도형이며 외부 아이콘 파일을 복사하거나 패키지에 포함하지 않았습니다.

- [Griddy Icons](https://griddyicons.com/): 실제 사이트에서 Chat Bubble, Chat Bubble Text, Layers, Layers Two의 형태를 비교했습니다. 일정한 선 굵기, 단순한 모서리와 내부 공간을 참고했습니다. 사이트는 24×24px 기준과 1.5px 선을 명시합니다.
- [SVG Repo · Chunk 16px Thick Interface Icons](https://www.svgrepo.com/collection/chunk-16px-thick-interface-icons/): 컬렉션 페이지의 정보는 확인했습니다. 브라우저에서는 보안 확인 화면에 걸려 개별 도형을 시각적으로 비교하지 못했습니다.
- [The Noun Project](https://thenounproject.com/): 픽토그램 탐색 출처로 확인했습니다. 개별 아이콘은 이번 후보에 사용하지 않았습니다.

미리보기에서는 형태 2종과 색상 3종을 독립적으로 고를 수 있습니다. 상세 대표 이미지, 메인 카드, 16·32·64·112px 아이콘, 별도 편집창의 파비콘 예시에 함께 적용됩니다. 포트폴리오 본편 자산과 사이트 파비콘은 바꾸지 않습니다.
