# Reference review

Reviewed on 2026-10-24. The eight repository READMEs are saved in this folder. Selected implementation files are saved under repository-name subfolders for inspection, not installed as global skills or executed.

| Source | Relevant technique | MMT use |
| --- | --- | --- |
| https://github.com/howseen-ai/claude-motion-design | Deterministic seek(t), camera target/scale, beat-aligned transitions, sound peak alignment. Reviewed `examples/howseen-launch/film.html`, `render.py`, `audio.py`, `fetch_assets.py`. | Rendering / camera / QA approach. The example's brand, copy and gradient aesthetic are not reused. |
| https://github.com/bangtutorial/bang-motion | Wide / close framing guided by important UI actions; shared element continuity. Reviewed `references/techniques.md`, `references/opener-konsep.md`. | Close views of actual MMT controls. |
| https://github.com/Barty-Bart/motion-graphics | Shape carries across scenes, closed-form damped motion; reviewed high-energy explainer and `motion-broll/engine/motion.js`. | Shared panel geometry and restrained spring math. |
| https://github.com/JohnHeibel/ClaudeAnimationBase | p5 character acting and hand-painted scene construction. | Not selected: a character narrative does not explain this desktop tool as directly as its UI. |
| https://github.com/latent-spaces/brag | Product-first project story, music/SFX assets with measured cues. | Source of music and selected Kenney sounds; no Hyperframes dependency added. |
| https://github.com/Vincentwei1021/mg-styles-15 | Shape Morph source (`demos/08-morph/index.html`), deterministic rendering and readable keyframe review (`rubric.md`). | Continuity and review criteria. No premade film or still is copied into MMT. |
| https://github.com/cth9191/animate | Beat table, visual proof before rendering, original screenshots / supplied product identity. | Brief and keyframe checks. |
| https://github.com/lemomo-ai/lemo-opuscar | Code-rendered frames, scene/score planning, readable frame checks. | Offline reproducible delivery approach. No demo footage reused. |

No claim is made that the entire video library has been watched frame by frame. Source and selected examples inform this specific film.
