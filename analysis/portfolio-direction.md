# 포트폴리오 방향성

## 소개의 중심

**Visual & AI Creator. — 아이디어를 영상과 도구로 구체화합니다.**

영상·모션 그래픽·AI 비주얼 제작과 프로그램 개발을 함께 보여준다. 특정 영상 장르, AI 제품명, 현재의 한 프로젝트를 전체 정체성으로 삼지 않는다. AI 도구를 많이 쓴다는 주장보다 어떤 결과물을 만들었고 직접 무엇을 판단·검증했는지 설명한다.

## 방문자가 읽는 순서

1. 메인: 작품 이름, 종류, 담당 범위를 확인한다.
2. 작품: 결과물을 본다.
3. 상세: 무엇을 만든 작업인지, 본인의 범위와 접근 방식, 제작 자료를 확인한다.
4. About: 전체 작업 방향과 핵심 역량을 확인한다. 전체 도구 목록은 펼쳐서 본다.
5. Contact: 영상·AI 비주얼·프로그램 제작에 관한 연락을 할 수 있다.

기존 카드 순서, 연출, 메뉴와 탐색 방식은 유지한다. 영상과 프로그램을 같은 포트폴리오 안에서 보여주며 별도 진입 장벽을 추가하지 않는다.

## 내용을 추가할 때의 기준

- 일반 소개에는 특정 도구나 프로젝트 이름을 고정하지 않는다. 이름과 버전은 각 프로젝트와 도구 목록에서 다룬다.
- 프로젝트 첫 설명은 결과물과 작업 성격부터 밝힌다. 모작·기존 소스 편집·개인 콘셉트를 상업 의뢰처럼 표현하지 않는다.
- 역할은 실제 담당한 범위만 적는다. 개인 기여도 100%는 해당 제작 범위를 설명하며, 기존 영화·브랜드·원작을 직접 창작했다는 의미로 사용하지 않는다.
- 선택한 방식과 작업 자료를 연결한다. 해결했다고 확인하지 않은 문제나 측정하지 않은 성과 수치를 만들지 않는다.
- AI 협업 개발은 단독 수작업 구현 경력으로 포장하지 않는다. 기능 정의, 사용 흐름, 실행 검증, 수정과 배포에서 직접 맡은 역할을 구체적으로 적는다.
- 새 작품은 기존 작품과 다른 역량이나 더 발전한 결과를 보여주는지 먼저 판단한다. 도구 목록을 늘리는 것으로 프로젝트 근거를 대신하지 않는다.

## 이번 반영

일반 소개·프로필·연락 문구의 방향을 맞췄다. 여섯 카드의 역할 요약과 작업 설명을 정리하고, 영상 상세의 Project Overview에서 결과물과 접근 방식을 설명했다. Sugar Rush는 뮤직비디오만이 아닌 캐릭터·AI 비주얼·웹사이트를 연결한 프로젝트로 소개한다. MMT는 도구가 하는 일을 첫 문장에서 설명하고, 기존의 실제 사례·검증·배포 내용을 유지한다.
