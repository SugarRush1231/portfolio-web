# Brand artwork used in the project intros

- Sugar Rush: [Allura Regular from Google Fonts](https://github.com/google/fonts/tree/main/ofl/allura), SIL Open Font License (Allura-OFL.txt). The handwritten title uses vector outlines derived from this font with animated stroke masks; joined words stay intact.

- Active fire texture (fire-rising.mp4): [Burning flames on a black background, Mixkit](https://mixkit.co/free-stock-video/burning-flames-on-a-black-background-3759/), offered under the Mixkit Stock Video Free License. Local file is a three-second silent excerpt starting at two seconds, retrieved 2026-10-20. The previous fire-texture.mp4 is retained as an unused earlier source.
- Initial D display substitute: Barlow Condensed ExtraBold Italic from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/barlowcondensed), SIL Open Font License (Barlow-OFL.txt). This is a racing-style substitute, not an official Initial D font or logo.

- Google G: vector silhouette and colors from Google's public [sign-in assets](https://developers.google.com/static/identity/images/signin-assets.zip), linked by the [official branding guide](https://developers.google.com/identity/branding-guidelines). The button surround is omitted; the logo artwork is retained. Assets retrieved 2026-10-20.
- Google Sans: official Google Fonts regular and bold faces, subset to the text “Google Chrome” for small local WOFF2 files. License: Google-Sans-OFL.txt. [Google's typeface background](https://design.google/library/google-sans-flex-font).
- CHANEL: exact vector wordmark outline displayed in the header of [chanel.com/us](https://www.chanel.com/us/), retrieved 2026-10-20. Used for the existing CHANEL concept-ad project; this is logo artwork, not a distributed CHANEL font file.

- Program icons: official Adobe SVG assets for [After Effects](https://main--cc--adobecom.aem.live/cc-shared/assets/img/product-icons/svg/after-effects-40.svg), [Premiere Pro](https://main--cc--adobecom.aem.live/cc-shared/assets/img/product-icons/svg/premiere-pro.svg), and [Photoshop](https://main--cc--adobecom.aem.live/cc-shared/assets/img/product-icons/svg/photoshop.svg), retrieved 2026-10-20. Stored locally with original artwork.

- Project navigation hover: adapted from [Nawsome’s arrow on Uiverse](https://uiverse.io/Nawsome/chilly-moose-65), reviewed 2026-10-21. The two-stage lower-to-upper highlight is redrawn with local SVG paths inside the existing circular controls. Attribution and MIT terms: Nawsome-arrow-MIT.txt.

- Contact reference study (2026-10-21): reviewed profile/contact listings and individual [alexruix](https://uiverse.io/alexruix/weak-lionfish-37), [Smit-Prajapati](https://uiverse.io/Smit-Prajapati/stupid-bullfrog-39), and [IWhat1](https://uiverse.io/IWhat1/strange-panther-78) card CSS. Local Contact composition uses original markup and styles; essential contact actions remain visible, with no hover-only reveal or flip.

Contact profile reveal (2026-10-21): inspired by https://uiverse.io/Centered101/cowardly-newt-15 (variation of Smit-Prajapati). Original local CSS uses transform/clip-path transitions, site theme colors, keyboard focus and a static expanded touch layout. No reference source code copied.

Contact card revised to follow the Centered101 reference square proportions, portrait morph and panel geometry; adapted CSS under MIT (Centered101-card-MIT.txt), with local theme colors, real portrait and accessible static touch state.

MMT installed-subtitles.png: captured live from the user-specified installed MMT.WinUI.exe (v1.4.0), 2026-10-21. Window title bar excluded to keep the cursor out of the published application content. Text case study based on user-provided AI_Operations_Portfolio.pdf; the PDF itself is not published.

MMT screen-content-v2.png: 8 px of remaining window edges trimmed from the live application capture. thumbnail-v2.svg: original title layout embedding that exact capture, with safe margins for the gallery's cover crop.
