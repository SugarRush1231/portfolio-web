투명 대화 · 합성용

파일 직접 열기에서는 투명 MOV를 저장할 수 없습니다. 먼저 프로젝트를 저장하고 로컬 서버 주소에서 열어 주세요. PNG·MP4·PNG 시퀀스 ZIP은 파일 모드에서도 저장할 수 있습니다.

대화 위치를 조절한 뒤 프로젝트와 PNG·MOV에 같은 배치를 저장합니다.

MOV는 ProRes 4444 + 알파 채널로 저장합니다. 프리미어에서 원본 영상 위에 얹으면 바로 투명하게 합성됩니다. 중간 PNG는 브라우저 메모리에서 처리하며 MOV 파일 한 개만 다운로드합니다. 합성용 대화 폭을 키워 출력한 뒤 편집기에서 줄여 쓸 수 있습니다. PNG 시퀀스는 30fps·최대 512MB이며, MOV 중간 프레임은 브라우저 메모리 보호를 위해 256MB까지입니다. MP4는 마젠타 크로마키 방식입니다.
